# kaigo-lp

介護領域向けLP（入居相談が増えるホームページ制作）のワイヤーフレーム。
メインテーマは入居者側の集客、採用はサブ。

## ファイル

| ファイル | 内容 |
|---|---|
| `kaigo-lp-wf.html` | LP本体のWF（1440px固定） |
| `case-neyagawaen-wf.html` | 「事例インタビューを詳しく見る」のリンク先（準備中の仮ページ） |

2ファイルを同じフォルダに置くと、ブラウザ上でリンク遷移できます。

## Figmaへの取込

- html.to.design（Chrome拡張）で取込。ウィンドウ幅は 1440px
- 取込順：`kaigo-lp-wf.html` → `case-neyagawaen-wf.html`
- flexのみ・実DOM・外部リソースなしで組んでいます

## 仮置き（公開前に要確認）

- FVの「約20倍」の表現（先方は実数を取っていないため、表現を要確認）
- お客様の声（那須さま・辻井さま）の掲載可否と役職表記
- Why us の根拠となる実績・経歴表記、担当メンバー名
- 制作期間、相談の所要時間・返信日数、対応エリア
- 採用代行の提供範囲
- 事例表「見学・入所相談」のBefore欄
